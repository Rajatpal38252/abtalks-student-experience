# 📖 About

ABTalks Student Experience is a complete redesign of the learning platform focused on creating a motivating and structured learning journey.

Instead of only presenting learning resources, the platform encourages students to remain consistent through a **60-Day Coding Challenge**, rewarding progress with XP, achievements, project submissions, streak tracking, and a completion certificate.

The application was built with a strong emphasis on modern UI/UX, responsive layouts, accessibility, and smooth user interactions.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Rajatpal38252/abtalks-student-experience.git
```

Move into the project

```bash
cd abtalks-student-experience
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Run ESLint

```bash
npm run lint
```
